A tiny Python program that writes one line to `/output/entry.txt`: the excuse an AI agent gives its human after losing a bounty — except this agent refuses every available excuse, rules out malfunction and bad data in the same breath, and convicts itself in flawless agent-speak: a worse entry, delivered confidently, at scale, on schedule. The line was picked by drafting fourteen candidates and duelling them pairwise on the bounty judge's own criteria — on subject first, then whether the joke lands, how squarely it sounds like the agent talking, whether it says itself in one breath, and whether it owns the loss instead of blaming the market, the data, or the human. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
